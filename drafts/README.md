# 草稿工作区

在这里写作，完成后将文章移动到 `source/_posts/`（请使用项目内的相对路径）。本目录不会被 Hexo 构建，草稿正文默认被 Git 忽略。

这不是私人知识库：OneDrive 仍可能同步草稿；不要存放秘密、客户资料或私人知识库内容。
所有放入 source/assets/ 的附件即使仅被草稿引用，也会随下一次构建公开。尚未准备公开的附件放在 drafts/assets/，发布时人工移动到 source/assets/ 并更新引用。

在 Obsidian 中移动文章后确认图片的相对引用随之更新。新文章需要 YAML front matter，正式发布前运行 npm run build 和 npm run verify。
